## 1. はじめに

本規約は、お客様に提供される **SHOGUN AI** デスクトップアプリケーション（以下「本ソフトウェア」）の利用条件を定めます。本ソフトウェアをインストール・起動・利用した時点で、本規約および販売者が提示する別途のライセンスに同意したものとみなします。

## 2. ソフトウェアの性質（ベータ・プレビュー）

- 本ソフトウェアは **開発・検証段階の機能を含む** 場合があります。挙動・API・データ形式は **予告なく変更**されることがあります。
- **macOS** を主な対象としています。他 OS 向けの動作保証は行いません。
- 画面に表示される **サブスクリプション料金・チーム・紹介コード等の一部 UI は、製品イメージまたは将来機能用**であり、**実際の課金決済（カード課金・App Store 課金等）が接続されていない**場合があります。その場合、ボタン操作はローカル設定の保存に留まることがあります。

## 3. Morning Brief・連携機能について

- **Morning Brief** は、設定により **スタブ（固定に近いサンプル）** または **ユーザー設定の LLM エンドポイント経由の生成** など、環境によって中身が異なります。常に特定の外部パイプライン（例: 社内 AMC）と同一とは限りません。
- **外部サービス連携（OAuth 等）** のうち、画面に「v1 で未対応」「not available」等が表示されるものは **本番接続されていない** 場合があります。プレビュー目的の UI が含まれます。

## 4. 第三者サービス

本ソフトウェアは、利用者の設定に応じて **OpenAI 互換 API**、**Clerk**（認証 UI）等の第三者サービスと通信することがあります。それぞれの提供条件・プライバシーは各事業者に従います。データの取り扱いの概要は [`PRIVACY.md`](../PRIVACY.md) を参照してください。

### 4.1 Clerk（サインイン・アカウント）

**Clerk** を有効にしたビルドでは、メール・Google 等によるサインイン／サインアップ等の UI が **Clerk のサービス（clerk.com）経由**で提供されます。**Clerk の利用規約・プライバシーポリシー等が、当該認証フローおよび Clerk が処理する個人データに適用されます。** 本アプリの Memory インデックス等のローカルデータとは別に、Clerk 機能の利用に伴い Clerk へ送信される情報が生じ得ます。運用では、承認されたキーとリダイレクト URL のみを設定してください。
