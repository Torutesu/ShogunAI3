# プライバシー概要（デスクトップ v1）

最終更新: 2026-04-18。説明用のメモです。英語版はリポジトリ直下の PRIVACY.md です。

## データの保存

- メモリ索引・設定などは、Mac 上のアプリケーション データ 領域に JSON で保存されます。
- LLM の API キーは macOS のログイン Keychain（サービス名 ai.shogun.desktop）に保存し、設定 JSON には書きません。

## ネットワーク

- チャットと Morning Brief は、ユーザーが指定した OpenAI 互換の HTTPS エンドポイントへ、Rust からリクエストが送られます。
- v1 では OAuth による外部サービス本番連携は行いません（画面はプレビューです）。

## 端末内の処理

メモリの検索・取り込み・削除、設定の読み書き、データ削除は Mac 上で完結します。
