# プライバシー概要（デスクトップ）

最終更新: 2026-07-15。説明用のメモです。正典は英語版 PRIVACY.md（リポジトリ直下）です。

## データの保存

- メモリ索引・設定などは、Mac 上のアプリケーション データ領域に保存されます。
- LLM / OAuth / Clerk / Deepgram / Cloud Mirror の各キーは macOS の Keychain（サービス名 ai.shogun.desktop）に保存し、設定 JSON には書きません。設定バックアップのエクスポートにもこれらのキーは含まれません。

## ネットワーク

すべて HTTPS。クラッシュレポートの外部送信は行いません。

- **利用統計（同意画面でオプトイン・いつでも解除可）**: 有効時のみ、**集計目的の最小情報**（アプリ起動と表示した画面の種類）を匿名のランダム端末IDで送信します。送信できるイベントはコード内の許可リストで固定されており、画面テキスト・メモリ内容・タイトル・検索語・ファイルパスが送られる経路は存在しません。解析キーが組み込まれていないビルドはトグルに関係なく何も送信しません。

- **LLM（BYOK）**: ユーザー指定のプロバイダ（OpenAI / Anthropic / Gemini 互換、ホストは許可リスト制限）へ、チャット・Morning Brief・下書き・KIOKU メモリ抽出/要約のためリクエストします。送信内容にはユーザーのテキストやローカルメモリの抜粋、（メモリ抽出が有効な場合）取得した画面テキストを含み得ます。
- **埋め込み（BYOK）**: 検索索引のため、メモリ項目テキストを OpenAI 互換 `/v1/embeddings` へ送信します。
- **会議文字起こし（Deepgram）**: 会議キャプチャ利用時、会議/システム音声を Deepgram（api.deepgram.com）へ送信します。この機能では音声が端末外に出ます。
- **連携（読み取り専用）**: 接続時に OAuth でデータをローカルメモリへ取り込みます（Gmail / Google Calendar / Drive / Slack / Notion / GitHub / Linear / Zoom / Outlook / Figma）。一部はプレビューで本番未接続です。
- **Cloud Memory Mirror（オプトイン・既定オフ）**: 有効化時、メモリ項目を端末側で E2E 暗号化（XChaCha20-Poly1305、サーバは内容・埋め込みを見られない）し、指定サーバへ同期します。同期管理用に「種別・出所・分単位の時刻」は平文で送られます。
- **課金 / アカウント（Clerk）**: 課金有効ビルドでは Clerk セッショントークンで entitlement を確認します。

## 端末内の処理

メモリの検索・取り込み・削除、設定の読み書き、キャプチャのフィルタ、データ削除は Mac 上で完結します。画面取得は **アクセシビリティのテキストのみ（スクショ・画面ピクセル取得は行いません）**。
