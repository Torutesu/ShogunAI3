Why now

断片化したAIツールの時代は、ここで終わる。

2007年、iPhone は「電話・カメラ・ブラウザ・音楽」をひとつのデバイスに統合した。

2026年、SHOGUN は「記憶・実行・データ主権」をひとつのOSに統合する。会議レコーダーは会議を覚える。ライフロガーは瞬間を覚える。SHOGUN は一日を覚え、そこから動きます。

Memory Layer

あなたが見たものを、あなたと同じ目線で記憶する。

SHOGUN が読むのは、macOS アクセシビリティ API 経由の「画面上のテキスト」だけです。スクショも動画も撮りません。取得は受動的で、フィルタ済みで、Mac の外に出ません。

ピクセルではなくテキスト

取得するのはアクセシビリティツリーのテキストのみ。パスワード欄・プライベートウィンドウ・決済ページは保存前に除外されます。

端末内で完結

記憶は Mac 内のローカルDBに保存。検索はミリ秒で返ります。あなたが許可しない限り外に出ません。

ログではなくグラフ

事実は人・決定・締切と結びつきます。古い記憶は減衰し、大事なものが手前に残る。

Execution Layer

行動しない記憶は、ただの日記です。

SHOGUN は記憶を 12 個の MCP ツールとしてエージェントに開放します。朝のブリーフはあなたが誰に何を借りているか知っている。下書きは実際に起きたことから始まる。会議はアーカイブではなく、フォローアップになる。

Morning Brief

昨日の記憶から「今日効く3つ」を毎朝。返信ドラフト付きで届きます。

下書きまで、できている

返信・フォローアップ・次の一手を、記憶から下書きします。送信ボタンを押すのは、あなたです。

12 MCP tools

Claude や任意の MCP クライアントに、あなたの文脈を接続。考える場所に記憶が付いてくる。

Trust

画面を見るツールだから、形容詞ではなく設計で信頼を作る。

  • ✓消すときは、生データまで消える。 期間削除は生キャプチャも同一トランザクションで削除します。
  • ✓キーは macOS Keychain に。 設定ファイルにもバックアップにも入りません。
  • ✓BYOK。 あなたの API キー、あなたのモデル、あなたの請求。内容が当社に渡ることはありません。
  • ✓利用統計はオプトイン、内容ゼロ。 起動と画面種別のみ。コード内の許可リストで強制されています。
  • ✓クラウド同期は既定オフ。 有効にしても端末側で E2E 暗号化。サーバが持つのは暗号文だけです。

上のすべては、コードから書き起こしたプライバシー文書で検証できます。読む →

FAQ

よくある質問

スクリーンショットを撮っているのですか？

いいえ。SHOGUN は macOS アクセシビリティ API 経由で画面上のテキストを読みます。スクショ・動画・OCR の仕組みはアプリ内に存在しません。パスワード欄・プライベートブラウズ・決済ページは保存前に除外されます。

記憶はどこに保存されますか？

Mac 内のローカルDBです。検索・ランキング・削除はすべて端末内で実行されます。クラウド同期は既定でオフ、有効化した場合も E2E 暗号化されます。

BYOK とは？

Bring Your Own Key。あなたが設定したモデルプロバイダ（OpenAI / Anthropic / Gemini 互換）を、あなたのキーで呼びます。内容が渡るのはあなたのプロバイダだけで、当社には渡りません。

動作環境は？

Apple Silicon の macOS です。ベータは未署名ビルドのため、初回のみ右クリック→「開く」で起動してください（macOS 15 以降はシステム設定 → プライバシーとセキュリティ →「このまま開く」）。

本当に全部消せますか？

消せます。期間指定の削除は、索引された記憶とその背後の生テキストの両方を削除します。全削除はローカルDBを消し、Keychain のキーもすべて消去します。
